# Тестирование

Функциональное тестирование выполняется вручную по сценариям ниже.
В столбце «Итог»: «+» — пройдена, «+-» — пройдена частично, «-» — не пройдена; подробности — в замечаниях.
Таблица переносится в раздел «Тестирование» пояснительной записки.

Характеристики: Windows 10 x64, NVIDIA GeForce RTX 5050 (драйвер 617.42), Python 3.11.9,
moderngl 5.13.0, glfw 2.11.0, imgui-bundle 1.93.0.
